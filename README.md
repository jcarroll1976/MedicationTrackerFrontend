Medication Tracking App - Frontend

Description

This is the frontend repository for a medication tracking application built with React. It provides users with a user-friendly interface to manage their medications, log dosages, and set reminders.

Key Features:

User authentication with Google,
Medication management (add, edit, delete),
Dosage logging and tracking,
Refill reminders, and
Customizable settings

React
Typescript
CSS

Prerequisites: Node.js and npm (or yarn) installed
Installation:

Clone the repository:

Bash
git clone https://github.com/jcarroll1976/MedicationTrackerFrontend
Use code with caution.

Install dependencies:

Bash
cd medication-tracker-frontend
npm install
Use code with caution.

Running the Development Server:

Start the development server:

Bash
npm start
Use code with caution.

The application will be accessible at http://localhost:3000.

The backend repository for this application can be found at https://github.com/jcarroll1976/MedicationTrackerBackend
